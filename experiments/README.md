# Experiments

Run `uv run cwi-evaluate` from the repository root. The command saves warehouse scenarios, BM25 checks, seeded clarification policy comparisons and integrated active-inspection comparisons as JSON. Run `uv run cwi-evaluate-llm --model NAME` separately with a local installed model.

The [research document](../docs/research/README.md) defines costs, assumptions and experimental limitations. [Recorded results](../assets/evaluation.json) contain executed synthetic results, not placeholders.
